# Safety, money and language (always)

- Never print `.env*` values or API keys. Show key names and whether they are set, only.
- Never commit `.env*`, `storage/`, rendered media, `*.safetensors` / `*.gguf` models or tokens.
- Ask the owner before:
  - paid generation (ElevenLabs, Leonardo, paid video APIs, X API);
  - posting to YouTube, Instagram, Facebook or X;
  - deleting remote database records;
  - installing software or npm packages;
  - pushing to GitHub.
- Free tools first: Edge voices, Remotion, local ComfyUI.
- Reply to the owner in simple English (short Roman Urdu is fine). Never Hindi or Devanagari script. The owner's voice typing may show Urdu in Devanagari; it is Urdu.
- Islamic content: never depict a prophet, companion or holy figure. Kids content: nothing scary or violent.
- Never use `--no-verify`. Fix what the hook reports.
